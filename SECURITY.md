# セキュリティの連絡先

このゲームで脆弱性を見つけたら、公開の Issue には書かず、GitHub の **Private vulnerability reporting** で知らせてください。

- 場所：このリポジトリの「Security」タブ →「Report a vulnerability」
- 対象：公開版（GitHub Pages）と、このリポジトリのコード・CI の設定
- 返事：個人で作っているので、目安は1週間以内です

このゲームは外部との通信・広告・アカウントを持ちません。個人の情報を集めることもありません。

## Security policy (English)

Please report vulnerabilities privately via GitHub's **Private vulnerability reporting** (Security tab → "Report a vulnerability"), not in public issues. We aim to reply within one week.
