# 脅威分析（STRIDE）

> NORI-35 でゲーム全体（公開サイト、CI、アセットの出所、AI 動画サービス、Jira の MCP）に広げる。今は NORI-17 の Blender MCP の節だけ。
> 重大度：高＝大事なファイル・個人の情報が外に出る／中＝作業が壊れる・やり直しが要る／低＝不便。

## 守るもの（資産）

| ID  | 資産                                                    | 置き場所                               |
| --- | ------------------------------------------------------- | -------------------------------------- |
| A1  | オーナーの個人のファイル（書類・写真・家族のデータ）    | オーナーのユーザーフォルダ、`G:\` など |
| A2  | 秘密情報（GitHub の認証、SSH の鍵、環境変数のファイル） | オーナーのユーザーフォルダ             |
| A3  | リポジトリ（ソース・履歴）                              | オーナーのユーザーフォルダの中         |
| A4  | 3D モデルの作業ファイル                                 | `C:\NoriBlender\work\`                 |

## Blender MCP（NORI-17）

AI が書いた Python を、確認の仕組みなしで Blender の中で実行する（公式ページの警告）。対策の詳細は `docs/security/blender-mcp-isolation.md`。

| ID   | STRIDE           | 脅威                                                                                      | 資産   | 重大度 | 対策                                                                                              | 状態                              |
| ---- | ---------------- | ----------------------------------------------------------------------------------------- | ------ | ------ | ------------------------------------------------------------------------------------------------- | --------------------------------- |
| B-01 | 情報漏えい       | AI のコード（またはプロンプトインジェクションで書かされたコード）が、個人のファイルを読む | A1〜A3 | 高     | 専用の標準ユーザー `noriblender` で Blender を動かす（ユーザーフォルダの権限で読めない）          | 手順あり・確認待ち                |
| B-02 | 情報漏えい       | 読んだものを外部へ送る                                                                    | A1〜A4 | 高     | ファイアウォールで `blender.exe` の外部への通信を止める（127.0.0.1 は通す）                       | 手順あり・確認待ち                |
| B-03 | 改ざん・妨害     | AI のコードがファイルを消す・書き換える                                                   | A3・A4 | 中     | 書けるのは `C:\NoriBlender\` だけ。できたモデルは GLB にしてリポジトリにコミット                  | 手順あり・確認待ち                |
| B-04 | 権限の昇格       | `_for_cli` の道具が、オーナーのユーザーで `blender --background` を起動して実行する       | A1〜A3 | 高     | Claude Code の deny で禁止＋ `BLENDER_PATH` を存在しない場所にする（二重）                        | `.mcp.json` 済み・deny はオーナー |
| B-05 | なりすまし       | 認証のない 9876 番に、同じ PC のほかのプログラムがつなぐ                                  | A4     | 低     | `localhost` だけで待ち受け（既定）。つないでも権限は `noriblender` のまま                         | 受け入れる                        |
| B-06 | 改ざん（供給網） | MCP サーバーや依存の中身が、知らないうちに変わる                                          | A1〜A3 | 中     | ソースをコミット ID で固定、依存は `--exclude-newer`（2週間ルール）。第三者製の似た名前を使わない | 済み（`.mcp.json`）               |
| B-07 | 情報漏えい       | スクリーンショットの道具で、Blender の画面（作業中のモデル）が AI サービスに渡る          | A4     | 低     | Blender の画面には自作のモデルだけを開く（家族の写真などを読み込まない）                          | ルール（CLAUDE.md）               |

ISO/SAE 21434 との対応：B-01〜B-04 はダメージシナリオ「個人の情報の漏えい」、対策①〜⑤は「サイバーセキュリティの目標」を満たす管理策にあたる。確認（隔離のテスト）は検証にあたる。
