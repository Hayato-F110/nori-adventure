# 企画書：のりものアドベンチャー（仮）

## コンセプト

**「ぼくの のりもので、せかいを ぐるっと ひとまわり」**
街・山・空・海・月を、5つの乗り物を乗りかえて旅する、やさしい3Dアクション。
失敗しても怒られない。ぶつかっても、その場からまた走り出せる。家族で横に座って「次はどこ行く？」と話しながら遊べるゲーム。

## 対象

| 項目      | 内容                                                                    |
| --------- | ----------------------------------------------------------------------- |
| 対象年齢  | 4〜8歳（字が読めなくても遊べる）と、その家族                            |
| 遊ぶ場所  | PC・タブレットのブラウザ（インストール不要。のちに PWA でオフライン可） |
| 1回の長さ | 1ステージ 2〜4分                                                        |

## 操作方法（文字に頼らない）

| 動き           | キーボード           | タッチ（タブレット）           | ゲームパッド |
| -------------- | -------------------- | ------------------------------ | ------------ |
| すすむ         | ↑ / W                | 右下の大きな ▶ ボタン          | A / RT       |
| さがる         | ↓ / S                | 右下の ◀ ボタン                | B / LT       |
| まがる         | ← → / A D            | 左下のハンドル（左右スライド） | 左スティック |
| 上下（空・海） | ↑ ↓ と Space / Shift | 左下のハンドル（上下）         | 左スティック |
| ミュート       | M                    | 右上のスピーカーアイコン       | —            |

ボタンは 64px 以上。説明は絵とアニメーションで見せる。

## ステージ

| ステージ | 場所 | 乗り物   | 遊びのポイント                             | ゴール                         |
| -------- | ---- | -------- | ------------------------------------------ | ------------------------------ |
| 1        | 街   | 車       | 基本操作を覚える。ほしを集めながらドライブ | チェックポイントを通ってゴール |
| 2        | 山道 | 列車     | 線路に沿うので「すすむ・とまる」だけ       | 駅に止まる                     |
| 3        | 空   | 飛行機   | 3次元。手を離すと自動で水平に戻る          | 輪をくぐってゴール             |
| 4        | 海   | 潜水艇   | 光と霧。暗い海で生きものを見つける         | たからばこを見つける           |
| 5        | 月面 | ローバー | 低重力でジャンプ。最後にボス戦             | ボスを落ち着かせてエンディング |

キャラクター・乗り物・世界観はすべてオリジナル（既存ゲームに似た名前・見た目・音は使わない）。

## 守ること

1. **強い罰を与えない**：ゲームオーバーなし。ぶつかったらその場から再開（短い無敵時間つき）
2. **隠れた補正を入れない**：勝ちやすくする・負けやすくする調整を、見えないところで入れない。入れるなら設定でオン・オフ
3. **こわくしない**：大きな音・急な音・暗すぎる画面を避ける。音量は控えめで、いつでもミュートできる
4. **外とつながらない**：外部への通信・広告・課金・アカウント登録なし
5. **個人情報を扱わない**：子どもの顔・声・写真を集めない、公開しない。テストプレイの記録は数値とメモだけ
6. **遊んだ人を喜ばせる**：家族のテストプレイの感想で直す（遊ぶ → 分析 → 直す）
