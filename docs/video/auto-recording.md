# プレイ映像の自動録画（NORI-42。案：オーナーの承認待ち）

紹介動画（5〜7分）の素材として、各ステージのプレイを Playwright で自動で録画する。人がキーを押す代わりに、E2E の運転役（`e2e/driver.ts`。NORI-37）が刻みごとに状態から入力を決めるので、**何度録っても同じ走り**になる。

仕様は [Playwright「Videos」](https://playwright.dev/docs/videos) と [browser.newContext の recordVideo](https://playwright.dev/docs/api/class-browser#browser-new-context) で確かめた（2026-11-13）。録画はブラウザのコンテキストを閉じたときに保存される。大きさは指定できる（指定しないと画面を 800×800 に収めた大きさ）。1 秒のコマ数は既定で 25。切り出し（トリミング）の機能はない。

## 決まり

| 項目             | 値                                                                                                                                         | 理由                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| 録る場所         | 手元の PC だけ（`npm run record`）。CI では録らない                                                                                        | CI は約 3 fps で、映像がカクカクになる。手元は 60 fps                                                     |
| 大きさ           | 1280 × 720（画面も同じ大きさにする）                                                                                                       | 動画の編集でそのまま使える 16:9。800×800 に縮めない                                                       |
| 速さ             | 早送りしない（運転役の `stepsPerFrame` を使わない。実際の時間どおり）                                                                      | 見る人が追える速さ。早送りは E2E の時間を短くするためだけ                                                 |
| 録るもの         | ステージ1〜5を、スタートからクリアのボタンが出るまで（ステージ5はエンディングまで）。1 ステージ 1 本                                       | 紹介動画で、どのステージも見せる                                                                          |
| 見せ場           | 走りの中の「とった」「チェックポイント」「ゴール」の刻み（状態の変化から決める。効果音と同じ決まり）を、録画のはじめからの秒で JSON に書く | どこを切り出せばよいかが、映像を見なくても分かる。決まった結果なので、毎回同じ秒                          |
| 見せ場のクリップ | 案A（おすすめ）：切り出しは編集のとき（JSON の秒を見て）。案B：ffmpeg を入れて、見せ場の前 3 秒・後 5 秒を自動で切り出す                   | 案A は新しい道具が要らない。案B は ffmpeg（外の道具）を入れることになり、入れる前に版と安全情報を確かめる |
| 置き場所         | `videos/`（Git の対象外）。リポジトリにも AI サービスにも入れない                                                                          | 動画は大きい。外へ出すかは、編集のときに決める                                                            |
| 映るもの         | ゲームの画面だけ（自作のモデル・CC0 の素材）。人の顔・声・家族の写真は入らない                                                             | 安全の決まり（CLAUDE.md）                                                                                 |

決めてほしいこと（オーナー）：見せ場のクリップの作り方（案A：JSON の秒だけ書き、切り出しは編集で、がおすすめ／案B：ffmpeg を入れて自動で切り出す）。
