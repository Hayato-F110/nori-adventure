## 決まったこと（2026-11-13 オーナー）

1. **下限は案 A**：命令 97%・分岐 89%・関数 99%・行 98%（測った値から約 1 点下げた値）。`vite.config.ts` の `coverage.thresholds`。下回ると `npm run coverage`（CI）が落ちる（分岐の下限を 99% にして、落ちることを確かめた）。カバレッジは「下がったことに気づく見張り」として使い、テストが十分かは、テストの一覧と初見レビューで見る
