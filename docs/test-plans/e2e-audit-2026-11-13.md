# E2E の総点検：実際の時間で待つ所の仕分け（2026-11-13、NORI-69）

CLAUDE.md「E2E は2種類に分ける」に照らして、`waitForTimeout`（実際の時間で待つ）と `keyboard.down`（本物の時間でキーを押す）を、すべて仕分けた（NORI-69 を始めたときに 36 か所）。

- **A**：ゲームを進めて結果を確かめる → 運転役（`e2e/driver.ts`）＋早送りにする。実際の時間で待たない
- **B**：実際の速さが要る（FPS・見た目・音・大人の長押し・クリア画面の 3 秒）→ そのまま。上限を決め、値を記録に残す
- **C**：キーボードの入力そのものが確かめる対象 → そのまま
