## 調べて分かったこと（一覧の前提）

   - 2026-11-17 に手元で確かめた（一時的なテスト `e2e/zz-repro84.spec.ts`。コミットしない）：ステージ3のコードの読み込みを `page.route` で 3 秒遅らせ、`sessionStorage` に `high` を入れて `?stage=3` を開いた。今の待ち方は 0.5〜0.8 秒で抜け、`cover` は undefined だった（形 A）。今の待ち方のあとに「`__nori.cover` ができるまで待つ」を挟むと、`source` は `"memory"`、`look` は `null` で、CI の 406 行と同じ形で落ちた（形 B）。直した待ち方（一覧 1）は 4.3〜4.5 秒待って、`look` が `"textured"` で通った
