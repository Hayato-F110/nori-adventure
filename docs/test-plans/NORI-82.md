## 調べて分かったこと（一覧の前提）

1. 公式の資料（https://code.claude.com/docs/en/hooks、2026-11-16 に読んだ）：PostToolUse の Hook は、終了コード 0 で標準出力に `{"hookSpecificOutput":{"hookEventName":"PostToolUse","additionalContext":"…"}}` を出すと、その文が道具の結果の横に入り、Claude が次に読む。オーナーの画面には出ない。道具が失敗したときは別の事象 PostToolUseFailure で、同じく `additionalContext` を使える。matcher を省くか `"*"` にすると、すべての道具が対象。文は 10,000 文字まで。命令の形でなく、事実を述べる形で書くよう書いてある
2. 今の `.claude/settings.json` の PostToolUse には、`Edit|Write|MultiEdit`（format-and-lint）と `SubagentHandback`（save-agent-report）がある。PostToolUseFailure はない
3. 今の Hook `japanese-reply`（`.claude/hooks/japanese-reply.mjs`）は、PreToolUse（道具の前の文）と Stop（この回の文章）で英語だけの行を見つけて止める。止めたことは、会話の記録（transcript）に残る：PreToolUse で止めたものは、道具の結果の失敗（`is_error: true`）の文の頭が「道具を呼ぶ前に止めました」。Stop で止めたものは、次のメッセージの「Stop hook feedback:」のあとに「止めました：この回の文章に、英語だけの行があります」
4. 道具の呼び出しは 1 回の作業で数十〜数百回ある。差し込む文は毎回会話に入るので、長くすると会話の量が増える
