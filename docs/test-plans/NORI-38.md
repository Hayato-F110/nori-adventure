## 調べて分かったこと（一覧の前提）

1. ページは `index.html` の1つだけ。ステージ2〜5は `src/main.ts` から `import()` で読む（ビルドでは別のファイルになる）。ポリシーは `public/privacy.html`
2. ビルドの `base` は `/nori-adventure/`（`vite.config.ts`）。ソースマップ（`.map`）も出る（`sourcemap: true`）
3. CSP（ページが読み込んでよい相手を決めるブラウザへの指示）は `index.html` の `<meta>` で、`default-src 'self'`・`script-src 'self' 'wasm-unsafe-eval'`。`worker-src` と `manifest-src` は書いていないので、`script-src`・`default-src` の `'self'` に従い、同じサイトの Service Worker（通信なしでもページを出すための、ブラウザの裏で動く仕組み）とマニフェストは許される。違反はコンソールのエラーに出るので、E2E のエラー 0 で見る
4. モデルは `public/models/manifest.json` を `fetch` で読んでから GLB を読む（`src/main.ts`）。どちらもビルドのファイルに入る
5. まだ Service Worker・マニフェスト・アイコンはない
