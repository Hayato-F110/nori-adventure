# Android アプリと Google Play での公開（計画の変更）

> 2026-11-10 にオーナーが承認。公式のページは 2026-11-10 に確認した。値や決まりは変わるので、各作業の直前にもう一度確かめる。

## 1. 決まったこと

| 事柄       | 決定                                                                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 届け先     | **Android だけ**（スマホ・タブレット）。Google Play で**無料**、世界中へ。広告・課金・データの収集なし                                     |
| 作り方     | **Capacitor**（ゲームのファイルをアプリの中に入れる）。TWA（公開サイトを開く方式）は使わない（3章）                                        |
| 開発の道具 | PC に入っている Android Studio（SDK の android-36 あり）。ネイティブのコードは、Capacitor が作る Java のひな形をそのまま使い、ほぼ書かない |
| 見た目     | もっとリアルに。house_render の方法をリアルタイム向けに使う（NORI-56。ステージ1で試してから広げる）                                        |
| 差別化     | 文字なし・罰なし・順位なし・隠れた補正なし・データを集めない・5種類の乗り物。追加でリプレイ（NORI-57）                                     |
| 外したもの | NORI-38（PWA）・NORI-46（テロップのスキル化）・NORI-40・44（AI 映像。Google AI Plus は申し込まない）。バックログに残す                     |
| 移したもの | NORI-27・28（ステージ3・4）をスプリント3へ                                                                                                 |

## 3. Google Play の決まり（公式で確認）

| 事柄               | 内容                                                                                                                                                          | 出典                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 登録               | 1回 US$25。身分証とクレジットカード（法的な氏名のもの）。18歳以上                                                                                             | [6112435](https://support.google.com/googleplay/android-developer/answer/6112435?hl=en)           |
| 実機の確認         | 新しい個人アカウントは、Play Console のアプリで Android の実機（Android 10 以上・root なし）を持っていることを確かめる                                        | [14316361](https://support.google.com/googleplay/android-developer/answer/14316361?hl=en)         |
| **公開される情報** | 個人アカウントは**法的な氏名・国・開発者のメール**が Google Play に出る。収益化すると住所も。開発者名は法的な氏名と違ってよい                                 | [13628312](https://support.google.com/googleplay/android-developer/answer/13628312?hl=en)         |
| 組織アカウント     | D-U-N-S 番号が要る                                                                                                                                            | [13634885](https://support.google.com/googleplay/android-developer/answer/13634885?hl=en)         |
| クローズドテスト   | 2023-11-13 より後に作った個人アカウントは、**12人以上が14日間続けて参加**したあとでないと本番に申請できない。審査は通常7日以内                                | [14151465](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en)         |
| ターゲット API     | 新しいアプリは Android 16（API 36）以上                                                                                                                       | [target-sdk](https://developer.android.com/google/play/requirements/target-sdk)                   |
| 子ども専用のアプリ | 承認されていない SDK は不可。広告 ID などの送信は不可。位置の権限は不可。プライバシーポリシーが要る。COPPA・GDPR などに従う                                   | [Families ポリシー](https://support.google.com/googleplay/android-developer/answer/9893335?hl=en) |
| web view           | 「ウェブサイトを web view で見せるだけ」のアプリは不可（サイトの持ち主の許可がない場合）。TWA の名前は出てこないが、誤解を避けるため Capacitor にする（解釈） | 同上                                                                                              |

## 5. 未決のこと

| 事柄                | 内容                                                                                                                    |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| アカウントの種類    | 個人だと本名が Google Play に出る。組織（D-U-N-S が要る）ならクローズドテストの決まりもない。登録の前にオーナーが決める |
| GitHub Pages の扱い | Android だけにするので、ゲームの公開版を残すか。プライバシーポリシーの置き場としては使う案                              |
| テスターの集め方    | 家族・友人の大人で 15人ほど（12人を割らないように余裕を見る）                                                           |
