プライバシーポリシー

「のりものアドベンチャー」 ／ 制定：2026年11月12日

まとめ

このゲームは、遊ぶ人の情報を集めません。どこにも送りません。広告・課金・アカウント（登録）・アクセス解析・cookie はありません。

集める情報

ありません。名前・年齢・メールアドレス・位置・写真・声など、個人の情報をたずねることも、読み取ることもありません。遊んだ記録をサーバーに送ることもありません。

端末の中に残すもの

次の3つだけを、ブラウザの保存場所（localStorage）に残します。

  • 画面の右上のボタンで選んだ「画質」（自動・高・低。名前は nori-adventure.quality）。次に開いたときに同じ画質で始めるためです。
  • クリアしたステージの番号（1〜4。名前は nori-adventure.cleared）。タイトル画面で、クリアしたステージに星の印を付けるためです。遊んだ時間や点数は残しません。
  • 画面の右上のボタンで選んだ「音あり・なし」（名前は nori-adventure.sound）。消音にしたら、次に開いたときも静かなままにするためです。

これらの情報はお使いの端末の中にだけあり、外へは送りません。ブラウザの設定で、このサイトのデータを消すと消えます。

通信

ゲームが読み込むのは、このサイトに置いたゲームのファイル（プログラム・3D モデル・画像）だけです。ほかのサイトへの通信は、ブラウザの仕組み（Content Security Policy）で止めています。

置き場所（GitHub Pages）について

このゲームは GitHub, Inc. の GitHub Pages に置いています。GitHub は、セキュリティのために、サイトを訪れた人の IP アドレスを記録・保存します（GitHub にログインしているかどうかによりません）。これは GitHub の仕組みです。このゲームの作者は、この記録を見たり使ったりしません。詳しくは About GitHub Pages（Data collection） と GitHub のプライバシーステートメント をご覧ください。

お子さまの利用

4〜8歳のお子さまとご家族が遊ぶことを考えて作っています。個人の情報をたずねないので、お子さまだけで遊んでも情報が集まることはありません。

Privacy Policy

Nori Adventure (のりものアドベンチャー) / Effective: November 12, 2026

Summary

This game does not collect any information about players and does not send any data anywhere. There are no ads, no purchases, no accounts, no analytics and no cookies.

Information we collect

None. The game never asks for or reads personal information such as names, ages, email addresses, location, photos or voices. It does not send play records to any server.

What is stored on your device

Only these three things are kept in your browser's storage (localStorage):

  • The graphics quality you choose with the button at the top right (auto, high or low; key nori-adventure.quality), so the game starts with the same quality next time.
  • The numbers of the stages you have cleared (1 to 4; key nori-adventure.cleared), so the title screen can show a star on them. No play time or scores are kept.
  • Whether sound is on or off, chosen with the button at the top right (key nori-adventure.sound), so the game stays quiet next time if you muted it.

This information stays on your device and is never sent anywhere. You can delete it by clearing this site's data in your browser settings.

Network

The game only loads its own files (program, 3D models and images) from this site. Connections to any other site are blocked by the browser (Content Security Policy).

Hosting (GitHub Pages)

This game is hosted on GitHub Pages by GitHub, Inc. For security purposes, GitHub logs and stores the IP address of visitors, whether or not they are signed in to GitHub. This is part of GitHub's service; the author of this game does not view or use these logs. See About GitHub Pages (Data collection) and the GitHub General Privacy Statement.

Children

The game is made for children aged 4 to 8 and their families. Because it never asks for personal information, no information is collected even when a child plays alone.

Changes and contact

If this policy changes, this page will be updated together with the date above. For questions, please use GitHub Issues (a GitHub account is required to post). It is a public place, so please do not write your name or other personal information there.

If you find a security problem, please do not post it in Issues. Report it through the private reporting form instead (a GitHub account is required; only the maintainer and you can see the report. See GitHub Docs: Reporting privately).
